CustomDailyRewards Wiki

A configurable daily rewards plugin for Paper 1.21.8 / Java 21 featuring a live GUI, built-in editor, and NPC support.

Modrinth Page

Download the plugin and check for updates.

Modrinth

Overview & Features

  • In-game GUI Editor: Create, edit, and delete rewards directly in-game without touching files.
  • No Dependencies: Built-in NPC system (no Citizens required) and default SQLite cooldown storage.
  • Integrations: Seamless LuckPerms support for rank-gated rewards and ExcellentCrates hook.
  • Advanced Mechanics: Live per-second countdowns, auto-claim options, and dynamic custom model data.

Commands

/daily - Opens the main rewards menu.
/daily settings - Opens the Reward Manager (In-game Editor).
/dailyadmin reload - Reloads config.yml and reward files.
/dailyadmin reset <player> - Clears all cooldowns for a specific player.
/dailyadmin npc <create/remove> - Spawns or removes the nearest Daily Rewards NPC.

Permissions

customdailyrewards.use - Allows opening the rewards GUI (Granted by default).
customdailyrewards.admin - Full administrative access to /daily settings and /dailyadmin.
