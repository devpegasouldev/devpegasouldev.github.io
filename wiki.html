CustomDailyRewards

A configurable daily rewards plugin for Paper 1.21.8 / Java 21.

Modrinth Page

Download the plugin and check for updates.

Modrinth

Commands & Permissions

Command Permission Description
/daily customdailyrewards.use
(default: true)		 Opens the rewards GUI (admins also see a shortcut button into settings).
/daily settings customdailyrewards.admin
(default: op)		 Opens the Reward Manager GUI.
/daily language customdailyrewards.use
(default: true)		 Opens the language selector.
/dailyadmin reload customdailyrewards.admin Reloads config.yml and all reward files.
/dailyadmin reset <player> customdailyrewards.admin Clears all cooldowns for a player.
/dailyadmin npc create customdailyrewards.admin Spawns a Daily Rewards NPC at your location.
/dailyadmin npc remove customdailyrewards.admin Removes the nearest Daily Rewards NPC.

Per-Reward Permissions

Permissions for specific rewards (e.g. customdaily.void) are defined directly inside each reward's own configuration file, and checked automatically through LuckPerms whenever it's installed.

In-game GUI Editor

The plugin ships completely clean, with no hardcoded rewards. Everything is managed entirely in-game through the /daily settings command (requires OP or customdailyrewards.admin).

Reward Manager

  • Emerald Button: Instantly creates a new reward with sensible defaults and opens it in the editor.
  • Left-click: Opens the Reward Editor for the selected item.
  • Shift + Right-click: Deletes the reward file and removes it from memory instantly.

Chat-Input System

  • Text fields use a smart chat-input pattern instead of an anvil GUI.
  • Click a property, then type your change directly into chat.
  • Type cancel to abort, or clear to wipe lists like lore and commands.
  • Every change is saved straight to the reward's YML file, instantly.

Editable Properties

  • Name & Lore: Supports MiniMessage formatting.
  • Commands: Console commands with %player% and %amount% placeholder support.
  • Cooldowns: Simple duration formatting (e.g. 2h30m, 90m).
  • Required Rank: Direct LuckPerms integration.
  • Display Item: Click with an item on your cursor to inherit its material — plus its exact custom name and lore, if it has any.
  • Toggles: One-click switches for Glowing, Auto-Claim, and Broadcast on Claim.
  • Custom Model Data: Click while holding a resource-pack item to inherit its material and model data in one step, or type a value manually in chat.

Both the Reward Manager and the Reward Editor are fully localized — every button, lore line, and toggle status renders in whichever language the viewing admin has selected, not just the player-facing menu.

Language Selector

Every player-facing message is available in five languages out of the box: English, Hungarian, German, French, and Spanish. Players choose their own language independently of the server's default, and the choice is remembered across sessions.

How It Works

  • Run /daily language to open the selector and pick a language with a single click.
  • The selection is saved per player and takes effect immediately, no rejoin required.
  • Server operators set the default language for new players in config.yml.

Supported Languages

  • English, Hungarian, German, French, and Spanish, fully translated.
  • Every translation file lives in its own editable YML, ready for further customization.
  • Any missing text automatically falls back to English, so nothing is ever left blank.

NPC

The plugin ships its own lightweight NPC system — no Citizens or other dependency required. Spawn one anywhere, and players can right-click it to open the exact same rewards menu as /daily.

Setup

  • /dailyadmin npc create spawns an NPC at your exact location.
  • /dailyadmin npc remove removes the nearest one.
  • Fully configurable in config.yml: entity type, display name, and glow effect.

Player-Facing by Design

  • The NPC always opens a plain rewards menu — the admin Reward Manager shortcut never appears there, even for OPs.
  • Admins reach settings through /daily settings or the shortcut button shown inside the command-opened menu instead.
  • Cooldowns, permission locks, and live countdowns behave identically to opening the menu with /daily.

psItemJoin

A fully GUI-driven join-item plugin for Paper 1.21.8 / Java 21. No file editing required, ever.

Modrinth Page

Download the plugin and check for updates.

Modrinth

Overview

psItemJoin gives players configurable items the moment they join your server — welcome kits, gadgets, cosmetic tools, or rank-gated perks. Every property of every item is built and edited entirely through an in-game GUI. There is no config file to hand-edit and no server restart needed to test a change.

Commands & Permissions

Command Permission Description
/psitemjoin settings psitemjoin.admin
(default: op)		 Opens the Item Manager GUI — create, edit, and delete join items.
/psitemjoin reload psitemjoin.reload
(default: op)		 Reloads config.yml, the language file, and every stored item.
/psitemjoin give <player> <itemId> psitemjoin.admin Manually gives a configured item to an online player, bypassing join logic.
/psitemjoin help - Lists all available sub-commands.

Additional Permissions

  • psitemjoin.bypasscooldown — skip an item's command cooldown (default: op).
  • <custom node> — any permission you set per item to gate who receives it (e.g. vip.gadget).

The In-Game Admin GUI

Running /psitemjoin settings opens the Item Manager: every join item as a clickable icon, plus a button to create a new one from scratch. Clicking any item opens its dedicated Item Editor.

Material & Appearance

  • Hold any item from your own inventory and click the editor's preview slot.
  • Its Material, Display Name, Lore, and Custom Model Data are copied instantly.
  • Display Name and Lore can also be retyped freely through the chat-input system.

Chat-Input System

  • Text fields (name, lore, permission, slot, cooldown) use chat input instead of an anvil GUI.
  • Click a property, then type your change directly into chat.
  • Type cancel to abort at any point.
  • Lore accepts one line per message — type done to finish.

Item Flags

  • Un-droppable: blocks the item from being dropped.
  • Un-placeable: blocks the item from being placed as a block.
  • Un-moveable: locks the item to its assigned slot inside the player's inventory.
  • Keep on death: the item survives death and is returned on respawn.
  • Glow: a one-click enchantment glint toggle, no enchant required.

Slot Assignment

  • Type any inventory slot from 0-35, or 40 for the offhand slot.
  • The editor preview shows whether the chosen slot is Hotbar, Inventory, or Offhand.
  • If a slot is already occupied on join, the item overwrites whatever is there.

Command Execution

Attach any number of commands to an item, each bound to either a left-click or a right-click. The Commands screen lets you pick the trigger and executor (Console or Player) before typing the command itself in chat — the %player% placeholder is replaced with the clicking player's name.

World Selection (Multiverse Support)

The World Selector reads Bukkit.getWorlds() live, so every currently loaded world — vanilla or Multiverse — appears automatically as its own toggle icon. Enable "Allow All Worlds" to hand the item out everywhere, or disable it and toggle specific worlds on individually (for example: given in lobby, withheld in survival).

Bonus Features

Permission / Rank Gating

Require a specific permission node before an item is granted — perfect for VIP gadgets or rank-exclusive starter kits. Leave it blank and the item is given to everyone.

First Join vs. Every Join

Toggle whether an item is handed out on every single login, or only once, the very first time a player ever joins. First-join records are tracked per player, per item.

Command Cooldown

Set a per-item cooldown, in seconds, to stop players from spam-clicking a bound command. Players with psitemjoin.bypasscooldown skip the wait entirely.

Language Selector

Every admin-facing GUI title, chat prompt, and system message is pulled from an editable language file. English and Hungarian ship out of the box, selected via language in config.yml.

How It Works

  • Set language: en or language: hu in config.yml.
  • /psitemjoin reload applies the change immediately, no restart required.
  • Any missing key automatically falls back to English so nothing is ever left blank.

Editable Files

  • Each language lives in its own file under /lang/ (e.g. en.yml, hu.yml).
  • Server owners are free to add further languages by copying the file structure.
  • Covers GUI titles, chat prompts, and every system message.
