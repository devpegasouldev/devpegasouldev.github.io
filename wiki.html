Modrinth

Key Features

  • GUI Menu: Interactive interface (`/daily`) with live, per-second countdown timers.
  • Modular YML Storage: Individual configuration files under `plugins/CustomDailyRewards/rewards/` for each reward.
  • Built-in NPC: Dependency-free NPC support (no Citizens required) that opens the GUI on right-click.
  • LuckPerms & ExcellentCrates: Seamless rank-gating, permission checks, and console command execution.

Commands & Permissions

Command Permission Description
/daily customdailyrewards.use Opens the rewards GUI
/dailyadmin reload customdailyrewards.admin Reloads config and reward files
/dailyadmin reset <player> customdailyrewards.admin Clears cooldowns for a player
/dailyadmin npc create customdailyrewards.admin Spawns a Daily Rewards NPC
/dailyadmin npc remove customdailyrewards.admin Removes nearest NPC

✨ New: In-Game GUI Editor

The latest version introduces a complete, interactive in-game editor. You no longer need to manually edit YAML files to manage your daily rewards!

Reward Manager

Create, delete, and modify individual rewards directly from a graphical interface. Adjust items, slots, and cooldowns with a few clicks.

Interactive Chat Input

When modifying text fields (like commands, names, or lore), the GUI will prompt you to seamlessly type your exact input into the game chat.

Settings Panel

Configure core plugin settings, such as the main GUI title, menu size, and localized messages, without touching the config.yml.

Live YML Updating

All changes made in the Editor GUI are instantly and safely saved to their respective configuration files in real-time.

Reward Configuration Example

Example structure for files inside `plugins/CustomDailyRewards/rewards/*.yml`:

name: "<light_purple>Void Reward</light_purple>"
material: ENDER_EYE
slot: 13
permission: "customdaily.void"
cooldown-hours: 24
commands:
- "crates give %player% eteri 1"
